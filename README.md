## 🚀 Hakkında (About)

Bu proje, **Osmancan Altınkaynak**'ın web ve mobil geliştirme alanındaki çalışmalarını, teknik yetkinliklerini, deneyimlerini ve projelerini sergilediği modern portfolyo web sitesidir.

## ✨ Öne Çıkan Özellikler

- 📱 **Tam Duyarlı (Responsive) Tasarım:** Masaüstü, tablet ve mobil cihazlarla tam uyumlu arayüz.
- 🎨 **Modern & Estetik Arayüz:** Akıcı tipografi, organik gölgeler ve interaktif hover efektleri.
- ⚡ **Yüksek Performans:** Saf (vanilla) HTML, CSS ve JavaScript mimarisi ile ultra hızlı yükleme süresi.
- 🛠️ **Yetenek & Proje Vitrini:** Seçili projelerin ve teknik bilgi birikiminin modern kart yapısıyla sunumu.
- 📬 **Sosyal & İletişim Entegrasyonu:** LinkedIn, GitHub ve doğrudan e-posta bağlantıları.

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Semantik ve erişilebilir sayfa yapısı
- **CSS3:** Modern Grid & Flexbox, tema değişkenleri (CSS Custom Properties), animasyonlar
- **JavaScript (ES6+):** Temiz, hafif ve etkileşimli kullanıcı deneyimi

## 📁 Proje Yapısı

```
.
├── index.html       # Ana sayfa iskeleti ve içerik
├── style.css        # Tasarım, tema değişkenleri ve responsive kurallar

```

## 💻 Yerel Geliştirme (Local Setup)

Projeyi yerel ortamınızda çalıştırmak için:

1. **Repoyu klonlayın:**
   ```bash
   git clone https://github.com/osmanncan/Portfolio.git
   ```

2. **Proje dizinine gidin:**
   ```bash
   cd Portfolio
   ```

3. **Bir yerel sunucu başlatın veya `index.html` dosyasını tarayıcınızda açın:**
   ```bash
   # Python ile
   python -m http.server 8000
   ```
